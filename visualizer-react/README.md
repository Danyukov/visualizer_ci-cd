# React 18 + TypeScript + React Query + ShadCN/UI (Vite 5)

This application is built with React 18, TypeScript, React Query, ShadCN/UI, and Vite.js (version
5). Below is a guide on how to set up and run the project, along with a brief overview of the
directory structure and key technologies.

## Main Technologies and Features

1. **React 18** — the latest version of React, offering enhanced performance and new rendering
   features.
2. **TypeScript** — provides static typing on top of JavaScript, improving reliability and developer
   experience.
3. **Vite.js 5** — an extremely fast build tool and dev server for React apps, making local
   development quick and straightforward.
4. **React Query** — a library for server state management (fetching/caching/sync), built on React
   hooks.
5. **ShadCN/UI** — a set of reusable components based on Radix UI and Tailwind CSS, facilitating
   consistent UI design.
